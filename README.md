# 70th Kerala Senior State Basketball Championship 2026

Live results, box scores, standings and player leaderboards for the men's and women's championship, Thalassery, Kannur, 3–8 November 2026.

**Live stats:** https://josu11stats.github.io/kerala-senior-basketball-2026/

Results are published by the official statisticians as soon as each box score is checked. Open pages update by themselves within about a minute.

## What is here

- `index.html`: the public site. It reads `data.json`, so visitors only ever see the results.
- `admin.html`: the statisticians' upload page. Publishing needs a personal upload key, which stays on the statistician's own device and is never stored here.
- `data.json`: every result, squad and fixture.
- `.github/workflows/social.yml` and `tools/social.mjs`: make the Instagram images after each publish and the day's recap carousel.
